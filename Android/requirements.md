# YMusicPlayer Android 版需求细节文档

## 1. 项目定位

YMusicPlayer Android 版不是把现有 Electron 桌面端直接打包成 APK，而是在保留当前桌面项目结构不变的前提下，在根目录 `Android/` 下开发独立移动端项目。

Android 版目标：

- 保留桌面版核心能力：本地音乐播放、歌词、歌单、云音乐搜索/下载、AI 发现推荐。
- 重新设计移动端交互和页面结构，避免直接套用桌面侧边栏布局。
- 将可复用的业务逻辑逐步抽象为跨端共享模块，但不破坏现有 Electron 桌面端。
- Android 端优先保证系统级体验：后台播放、通知栏控制、权限、下载任务、媒体库扫描。

## 2. 当前桌面项目功能点

### 2.1 本地曲库

当前桌面端支持：

- 添加一个或多个本地扫描目录。
- 递归扫描音频文件。
- 支持音频格式：
  - `.mp3`
  - `.flac`
  - `.wma`
  - `.wav`
  - `.m4a`
  - `.aac`
  - `.ogg`
- 使用 `music-metadata` 读取歌曲元数据：歌曲名、歌手、专辑、时长等。
- 识别同目录同名歌词文件：`.lrc`、`.txt`。
- 支持单曲重新导入/扫描。
- 支持云音乐匹配后补全本地曲目信息。

Android 版要求：

- 支持用户授权音乐目录或系统媒体库读取。
- 适配 Android scoped storage 权限模型。
- 支持 Android 13+ 媒体权限：`READ_MEDIA_AUDIO`。
- 支持 Android 12 及以下外部存储读取权限。
- 初版可优先使用系统 MediaStore 扫描音乐，后续再支持自定义目录扫描。
- 本地曲库需要持久化，不应每次启动全量扫描。
- 需要支持增量扫描、手动刷新、单曲导入。
- WMA 支持需要单独评估；如果系统解码不可用，初版可以标记为“不支持播放”或后续接入 FFmpeg。

### 2.2 播放能力

当前桌面端支持：

- 播放本地音频。
- 歌曲列表点击播放。
- 上一首/下一首。
- 播放/暂停。
- 音量控制。
- 进度条拖动。
- 播放模式。
- 播放失败提示。
- WMA 文件通过主进程调用 ffmpeg 转码为 wav buffer 后播放。

Android 版要求：

- 使用 Android 原生播放能力，优先考虑 ExoPlayer / Media3。
- 支持后台播放。
- 支持通知栏播放控制：播放、暂停、上一首、下一首、关闭。
- 支持锁屏控制。
- 支持耳机线控、蓝牙媒体按键。
- 支持音频焦点处理：来电、其他 App 播放音频时暂停或降低音量。
- 支持播放队列。
- 支持播放模式：顺序播放、列表循环、单曲循环、随机播放。
- 支持播放历史记录。
- 播放状态需要在页面、通知栏、后台服务之间保持一致。

### 2.3 歌单与收藏

当前桌面端支持：

- 内置固定歌单：`我喜欢`。
- 用户自建歌单。
- 歌单添加/移除歌曲。
- 删除歌单。
- 喜欢状态与 `我喜欢` 歌单联动。

Android 版要求：

- 保留 `我喜欢` 固定歌单。
- 支持创建、重命名、删除自建歌单。
- 支持将歌曲加入/移出歌单。
- 支持批量操作。
- 歌单数据需要本地持久化。
- 歌单引用应使用稳定歌曲 ID，不能依赖易变列表下标。

### 2.4 歌词

当前桌面端支持：

- 自动读取本地同名 `.lrc` / `.txt` 歌词。
- 支持多编码读取。
- 支持每首歌配置歌词编码。
- 支持 LRC 时间轴解析。
- 支持当前歌词高亮。
- 支持歌词偏移调整。
- 支持将偏移写回歌词文件。
- 支持桌面悬浮歌词窗口。
- 支持歌词查找窗口，通过 WebView 下载歌词并保存为同名文件。

Android 版要求：

- 支持本地歌词匹配：同目录同名 `.lrc` 优先。
- 支持云端歌词下载。
- 支持歌词时间轴解析和当前行高亮。
- 支持歌词偏移调整。
- 支持保存歌词偏移；初版可以保存到数据库，不直接改写原歌词文件。
- 支持无歌词状态提示。
- 支持纯文本歌词展示。
- 悬浮歌词属于高权限功能，初版不强制实现。
- 后续可选能力：
  - Android 悬浮窗歌词。
  - 通知栏歌词。
  - 锁屏歌词。

### 2.5 云音乐搜索与元数据匹配

当前桌面端支持云音乐网关：

- 支持来源：QQ 音乐、网易云音乐、酷狗音乐。
- 支持配置 API Base URL。
- 支持配置 API Key / sid。
- 支持单来源搜索。
- 支持多来源并发搜索。
- 支持每页数量配置。
- 支持搜索歌曲。
- 支持获取歌曲详情。
- 支持获取播放/下载直链。
- 支持获取歌词。
- 支持获取封面图。
- 支持测试连接。
- 支持本地曲库一键匹配云端元数据。
- 支持只补齐缺失歌词。
- 支持匹配后覆盖歌曲名、歌手、专辑。
- 支持匹配后自动下载同名 LRC。

Android 版要求：

- 保留云音乐网关配置能力。
- 云音乐 API Key 只保存到本机安全存储。
- 支持搜索页展示云端歌曲。
- 支持查看云端歌曲详情。
- 支持云端歌曲下载。
- 支持云端歌词下载。
- 支持云端封面展示。
- 支持本地歌曲云端匹配。
- 支持配置默认来源和启用来源。
- API 调用失败时需要明确提示：网络错误、鉴权失败、限流、无结果、音质不可用。

### 2.6 下载管理

当前桌面端支持：

- 下载云端歌曲。
- 下载任务持久化。
- 下载状态：排队中、下载中、暂停、完成、失败、取消。
- 最大并发任务数配置。
- 分段下载。
- Range 探测。
- 音质选择：
  - `MP3_128`
  - `MP3_320`
  - `FLAC`
  - `ATMOS`
  - `ATMOS2`
- 音质不可用时自动降级。
- 下载完成后自动导入本地曲库。
- 下载完成后自动下载歌词。
- 下载任务列表展示。
- 暂停、继续、删除、打开所在位置。

Android 版要求：

- 下载必须使用 Android 后台机制实现，不能依赖页面生命周期。
- 推荐使用 Foreground Service 或 WorkManager 组合。
- 下载中必须有通知栏进度提示。
- 支持暂停、继续、取消。
- 支持失败重试。
- 支持下载任务持久化。
- 支持选择下载目录，或默认保存到 App 音乐目录。
- 下载完成后触发媒体库扫描，让系统和 App 都能识别新歌曲。
- 支持自动下载歌词。
- 支持自动导入到本地曲库。
- 分段下载可作为第二阶段能力，初版可先实现稳定单连接下载。

### 2.7 AI 发现音乐

当前桌面端支持：

- 启用/关闭发现音乐。
- 支持 OpenAI-compatible `/chat/completions`。
- 支持 Anthropic-compatible `/v1/messages`。
- 支持配置 API Base URL、API Key、模型名称。
- 支持配置 temperature、max tokens、timeout。
- 支持读取本地曲库、收藏、歌单、听歌历史作为推荐依据。
- 可选发送短歌词片段。
- AI 只返回云端可搜索候选，不返回本地路径、trackId、云端 ID 或下载链接。
- 自动用云音乐搜索解析 AI 候选。
- 展示推荐理由、证据、置信度。
- 支持重新生成推荐。
- 支持隐私提示。

Android 版要求：

- 保留 AI 推荐配置。
- AI 请求不能发送本地文件路径。
- 只发送歌曲元数据、收藏、歌单、播放统计和可选歌词片段。
- AI 输出必须经过结构化 JSON 校验。
- AI 推荐结果必须通过云音乐搜索解析后才能提供下载或详情操作。
- 发现页必须适配移动端阅读体验。
- 暗色/亮色主题下文字必须清晰可读。
- 推荐失败、配置缺失、样本不足时需要明确提示。

### 2.8 设置

当前桌面端支持设置：

- 主题切换。
- 背景图选择。
- 背景模糊度。
- 文件夹管理。
- 关闭行为。
- 云音乐设置。
- AI 推荐模型设置。
- 下载设置。
- 歌词编码设置。

Android 版要求：

- 设置页按移动端分组展示。
- 配置项需要本地持久化。
- 敏感信息如 API Key 不应明文暴露在普通页面。
- 支持清空播放历史。
- 支持清空下载任务。
- 支持清空 AI 发现缓存。
- 支持导出/导入配置可作为后续能力。

## 3. Android 页面要求

### 3.1 底部导航

Android 版建议使用底部 Tab，而不是桌面侧边栏。

建议主 Tab：

1. 曲库
2. 发现
3. 下载
4. 我的

### 3.2 曲库页

应包含：

- 歌曲列表。
- 歌手维度。
- 专辑维度。
- 文件夹维度。
- 搜索入口。
- 扫描/刷新入口。
- 当前播放迷你条。

### 3.3 播放页

应包含：

- 封面。
- 歌曲名、歌手、专辑。
- 喜欢按钮。
- 播放/暂停。
- 上一首/下一首。
- 进度条。
- 播放模式。
- 歌词区域。
- 更多操作：加入歌单、云端匹配、下载歌词、查看文件信息。

### 3.4 发现页

应包含：

- 当前配置状态。
- 推荐依据摘要。
- 生成/重新生成按钮。
- AI 推荐列表。
- 推荐理由、证据、置信度。
- 查看云端详情。
- 下载。
- 手动搜索未解析项。
- 隐私说明。

### 3.5 下载页

应包含：

- 下载中任务。
- 已完成任务。
- 失败任务。
- 暂停/继续/取消/删除。
- 下载进度、速度、大小。
- 下载设置入口。

### 3.6 我的/设置页

应包含：

- 歌单管理。
- 云音乐配置。
- AI 模型配置。
- 下载配置。
- 本地扫描配置。
- 主题设置。
- 数据清理。
- 关于。

## 4. 数据存储要求

Android 版建议使用：

- Room：歌曲、歌单、播放历史、下载任务、AI 发现缓存。
- DataStore：普通设置项。
- EncryptedSharedPreferences 或 Android Keystore：API Key 等敏感配置。

核心数据表建议：

- `tracks`
- `playlists`
- `playlist_tracks`
- `listening_history`
- `download_tasks`
- `discover_cache`
- `cloud_matches`
- `lyrics`

## 5. 权限要求

Android 版需要考虑：

- Android 13+：`READ_MEDIA_AUDIO`
- Android 12 及以下：`READ_EXTERNAL_STORAGE`
- 下载到公共目录时的存储访问策略。
- 后台播放前台服务权限。
- 通知权限：Android 13+ `POST_NOTIFICATIONS`
- 可选悬浮歌词：`SYSTEM_ALERT_WINDOW`

初版不要强依赖悬浮窗权限。

## 6. 非功能要求

### 6.1 性能

- 曲库列表需要支持大量歌曲，不应一次性渲染全部复杂组件。
- 扫描任务不能阻塞 UI。
- 下载任务不能依赖 Activity 生命周期。
- AI 请求和云端搜索必须异步执行。

### 6.2 可靠性

- App 重启后播放状态、下载任务、曲库数据不能丢失。
- 下载中断后应可恢复或明确标记失败。
- API 配置错误不能导致页面崩溃。
- 本地文件被删除时应在播放或刷新时提示。

### 6.3 隐私

- AI 请求不发送本地文件路径。
- API Key 仅本机保存。
- 用户需要能清空播放历史和 AI 缓存。
- 发现页必须展示隐私说明。

### 6.4 主题

- 必须支持亮色/暗色主题。
- 所有页面文字颜色必须跟随主题。
- 暗色主题下不能出现黑字黑底。
- 发现页、设置页、下载页是重点检查页面。

## 7. 首版范围建议

首版 Android MVP 应包含：

- 本地曲库读取。
- 本地播放。
- 后台播放与通知栏控制。
- 喜欢和歌单。
- 基础歌词显示。
- 云音乐搜索。
- 云端歌曲下载。
- 设置页。

第二阶段再做：

- AI 发现推荐。
- 云端元数据一键匹配。
- 分段下载。
- 歌词偏移写回。
- 悬浮歌词。
- 跨端共享模块抽取。
